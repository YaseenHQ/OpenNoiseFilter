# OpenNoiseFilter — model tools

Model build tooling and benchmarks for the
[Web Audio package](../open-noise-filter/README.md) and
[native Rust crate](../open-noise-filter-rs/README.md).
This component is private build tooling, not a third installable runtime
library. The browser package ships prebuilt WASM assets; the Rust crate
vendors generated C. Consumers do not need this model-build toolchain.

## Layout

| path | what |
|------|------|
| `models/` | FastEnhancer `*_spec.onnx` (MIT, arXiv:2509.21867) |
| `scripts/` | ONNX lowering/normalization + onnx2c post-passes + verification |
| `shims/` | per-tier C shim: static caches + `fe_init/fe_run/fe_in_ptr/fe_out_ptr` |
| `build.mjs` | ONNX → C → WASM, per tier, SIMD and scalar variants |
| `verify.mjs` | WASM vs ONNX Runtime: single-frame specdiff + full-clip diff |
| `cost.mjs` | per-frame CPU cost through the real worklet code |
| `harness.mjs` | drives the browser component's worklet in Node (`$ONF_DIR`) |
| `bench/` | engine benchmark (108-clip DNSMOS/STOI/SI-SDR corpus) |
| `build/`, `out/` | gitignored intermediates and artifacts |

## Prerequisites

- **Python** with `numpy`, `onnx`, `onnxruntime` —
  `python -m venv .venv && .venv/Scripts/pip install -r scripts/requirements.txt`
  (or set `PYTHON`).
- **onnx2c** built from source (cmake + ninja + protobuf;
  <https://github.com/kraiskil/onnx2c>). Set `ONNX2C` to the binary; on
  Windows a WSL path (`/mnt/...`) is run through `wsl --exec`.
  Note: stock onnx2c hits four bugs on this graph — see
  [kraiskil/onnx2c#133](https://github.com/kraiskil/onnx2c/issues/133).
  The pipeline works around all of them (GRU/Gather lowering, the union→struct
  de-alias, the MatMul rewrite); no onnx2c patches are needed.
- **emscripten** (developed against emsdk 6.0.9). Set `EMCC` or have `emcc`
  on PATH.
- **Node** ≥ 18 and `npm install` (esbuild).
- The browser component next to this directory (`../open-noise-filter`, or
  `ONF_DIR`) — verification, timing, and rendering bundle its worklet.
  Keep the components as siblings in the combined repository.

Commands below run from `open-noise-filter-wasm/`. Shell examples use
Bash-style environment assignments. In PowerShell, set variables first,
for example `$env:ONNX2C = '/mnt/c/tools/onnx2c'`, then run the command.

## Build

```bash
ONNX2C=/path/to/onnx2c EMCC=/path/to/emcc node build.mjs
# subset:  node build.mjs --tier b --variant simd
```

Per tier `t`/`b`/`s`: `lower_gru.py` → `normalize.py` → `onnx2c` →
`dealias.sh` → `fastmatmul.py` → `emcc`. SIMD emits
`out/fastenhancer_{tier}.wasm` with `-O3 -msimd128 -ffast-math
-sSTANDALONE_WASM --no-entry` and the `fe_*` exports; scalar emits
`fastenhancer_{tier}_scalar.wasm` without `-msimd128`.

## Verify

```bash
node verify.mjs --variant simd
node verify.mjs --variant scalar
```

Each tier runs ORT reference generation, a single-frame spectrum diff
(<1e-3), and a 3 s whole-clip audio diff (<2e-3). Measured here: SIMD and
scalar both pass all tiers; scalar max diff ≈ 4e-6.

The previously verified SIMD builds had the same ABI and equivalent output
as the shipped assets, with a small binary difference. Toolchain versions
can change generated bytes; use the numerical checks and the recorded
distribution hashes rather than assuming byte-identical output.

## Frame cost

```bash
node cost.mjs --variant all
```

60 s of noise per build through the real worklet; timed calls are only those
where a model frame runs (first 400 quanta skipped). Budget: 2.667 ms per
audio quantum.

| tier | variant | median | p99 | max | >2.667 ms |
|------|---------|-------:|----:|----:|----------:|
| t | simd   | 0.536 | 0.714 | 1.040 | 0.0% |
| t | scalar | 1.245 | 1.972 | 2.570 | 0.0% |
| b | simd   | 1.888 | 3.113 | 5.539 | 2.2% |
| b | scalar | 4.786 | 5.983 | 8.378 | 100% |
| s | simd   | 4.326 | 5.202 | 7.104 | 100% |
| s | scalar | 11.598 | 13.515 | 24.482 | 100% |

(Measured on this machine; reruns move the numbers. Consequence for the
library's non-SIMD fallback: `low` stays on the audio thread in mono,
everything else neural goes to a worker, and `high` is unusable without
SIMD — a scalar Small frame costs ~11.6 ms median against a 10.67 ms hop.)

## Benchmark

See [bench/README.md](bench/README.md). Build the SIMD assets into `out/`
first (`node build.mjs --variant simd`), then follow that guide from `bench/`
to fetch the corpus, render, and score it.

## Consuming the artifacts

Copy the six tier assets (`fastenhancer_{t,b,s}.wasm` and their `_scalar`
variants) into `../open-noise-filter/wasm/`. Update the SHA256 table in
`../open-noise-filter/wasm/README.md`, then rebuild and test the browser
package. For Rust, copy the generated tier C files using the mapping in
its [model rebuild guide](../open-noise-filter-rs/README.md#rebuilding-the-model-sources).
